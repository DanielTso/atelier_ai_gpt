# ATELIER Master Brand Guideline v2

## Overview
Use this skill whenever an artifact, product, workspace, screen, report, website, slide, document, or planning system should reflect the ATELIER Technologies, Inc. brand.

This guideline defines the visual and verbal system for ATELIER and should shape all future branded work under the company.

Keywords: branding, corporate identity, visual identity, naming, product architecture, dashboard styling, app UI, mature software, executive design, calm systems, premium workspace

## 2) Visual Direction

### Primary Visual Position
**Light, modern, executive-grade software**

ATELIER should look like software built for serious adults doing real work.

The design should communicate:
- confidence without arrogance
- clarity without emptiness
- sophistication without coldness
- modernity without trend-chasing

### Design Philosophy
- Clean, not plain
- Minimal, not empty
- Professional, not corporate-boring
- Premium, not flashy
- Structured, not rigid
- Calm, not dull

### UI/UX Design Rules
- Prefer light backgrounds and dark text for the primary experience.
- Use restrained accent color, not loud contrast.
- Provide enough context that interfaces feel real and useful.
- Use whitespace, modular cards, and strong hierarchy to organize complexity.
- Make trust visible through evidence panels, summaries, status labels, and review states.
- Avoid dense clutter and avoid “blank concept page” minimalism.
- Favor rounded corners, soft shadows, subtle gradients, and layered surfaces.

## 3) Color System

### Core Palette

#### Primary Colors
- **Atelier Navy**: `#1F3447`
  - Primary navigation, authority, emphasis, dashboards, data framing
- **Steel Blue**: `#4F7396`
  - Primary accent, buttons, links, active states
- **Ink**: `#16202A`
  - Headings, body text, charts, main content
- **Canvas Light**: `#F7F6F2`
  - Primary page background
- **Pure Surface**: `#FFFFFF`
  - Cards, content surfaces, elevated panels
- **Warm Sand**: `#D9CFBF`
  - Borders, warm neutral accents, soft separators

#### Support Colors
- **Stone Sage**: `#8C9A86`
  - Calm secondary accent, supportive indicators, filtered states
- **Soft Mist**: `#F3F1EC`
  - Secondary backgrounds and modular panels
- **Muted Line**: `#E3DDD2`
  - Borders, rules, light structure
- **Slate Text**: `#6F7781`
  - Metadata, helper text, captions

#### Status Colors
- **Success Green**: `#3F7252`
- **Warm Warning**: `#A06D2E`

### Color Behavior
- Let neutrals carry most of the interface.
- Use blue as the main interactive accent.
- Use sage sparingly to soften dashboards and reinforce calmness.
- Use warm neutrals to prevent the brand from feeling icy or generic.
- Avoid neon colors, oversaturated gradients, and loud multi-accent palettes.

## 4) Typography Direction

### Style
Typography should feel:
- precise
- premium
- readable
- modern
- calm

### Recommended Primary Stack
- `Inter`
- `Segoe UI`
- `Helvetica Neue`
- `Arial`
- `sans-serif`

### Hierarchy Guidance
- Display headlines: large, tight tracking, strong weight
- Section headlines: medium-large, clean, confident
- Body copy: highly readable, moderate line length, neutral tone
- Metadata: smaller, muted, well-spaced

### Typography Rules
- Use size and spacing for hierarchy before using too many colors.
- Prefer clean sans-serif typography over decorative type.
- Use short, strong headlines.
- Keep body copy readable and not overly compressed.
- Avoid ultra-thin weights and overly geometric novelty fonts.

## 8) Artifact Styling Rules

### Documents
- Light background
- Strong headline hierarchy
- Use navy and blue sparingly for emphasis
- Wide margins and clean spacing
- Charts and tables should feel executive, not academic

### Presentations
- Minimal text per slide
- Soft neutral backgrounds
- One main visual message per slide
- Use cards and modular layouts instead of cluttered bullet slides

### Dashboards / Web Apps
- Light-first UI
- Professional cards and panels
- Clear metrics with supportive labels
- Visible review states and source evidence
- Clean primary CTA buttons in Steel Blue

### PDFs / Reports
- Prioritize readability and scannability
- Separate source evidence from generated summaries
- Use structured sections and labeled callouts
- Maintain a trustworthy, polished tone

---

## 9) Practical Brand Rule

Every ATELIER artifact should answer:
1. Does this feel clear?
2. Does this feel trustworthy?
3. Does this feel calm?
4. Does this feel premium but usable?
5. Would a serious professional feel comfortable using this daily?

If the answer is no, revise.
