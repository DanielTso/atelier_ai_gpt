# Auto-memory (suggest, you approve) Implementation Plan

## Context

**Why:** Auto-memory is the last of two deferred items from the v4.7–4.9 program (re-versioning shipped as v4.9.0). The user is a construction superintendent; durable job facts (PE of record, milestone dates, decisions) currently only enter a project's Memory if typed by hand. This feature proposes those facts automatically while keeping a human approval gate so Memory stays clean and trusted.

**What:** After exchanges in a **project** chat, a throttled best-effort Gemini Flash pass extracts candidate durable facts and stores them as *pending* suggestions. They surface in the project rail's Memory section with **Accept / Edit / Dismiss**. Accepting appends to the existing `projects.memory` field — already injected into every project chat via `buildProjectPreamble` and shown in the rail. Nothing enters Memory without a click.

**Outcome:** Memory accrues useful facts with near-zero user effort; ships as **v4.10.0**.

**Source spec:** `docs/specs/2026-06-19-auto-memory-design.md` (approved 2026-06-19).

**Goal:** Throttled (every 6 messages), capped (~10 pending) Gemini-Flash suggestion of durable project facts, reviewed via an Accept/Edit/Dismiss strip in the rail, accepted facts appended to `projects.memory`.

**Architecture:** New `memory_suggestions` table (migration `0008`). Six server actions in `src/app/actions.ts`. A new `POST /api/memory/suggest` route mirroring `/api/classify` (Gemini Flash → parse → fallback, key-guarded, never throws to the user). A "Suggested memories" strip added to `ProjectContextRail`'s Memory section (fetches on mount — the rail is only visible in the project landing view, so no live-refresh wiring is needed). A throttled best-effort trigger in `src/app/page.tsx`'s `useChat` `onFinish`.

**Tech Stack:** Next.js 16 App Router, Drizzle (`postgres-js`, pgvector), Zod, AI SDK v6 + `@ai-sdk/google` (`gemini-3.5-flash`), Vitest (PGlite for actions, `vi.doMock` scaffold for routes, jsdom for components), lucide-react, sonner.

## Global Constraints

- **Housekeeping model is `gemini-3.5-flash`** via `@ai-sdk/google` — never Claude tokens (mirror `/api/classify`).
- **All DB access goes through `'use server'` actions** in `src/app/actions.ts`. Client/route code never touches `db` directly.
- **All POST routes validate the body with a Zod schema** in `src/lib/validation.ts`; errors go through `apiError()` (`src/lib/errors.ts`). The suggest route must **never surface as a user error** — wrap in try/catch returning `apiError(error, '…', 200)`, and key-absent returns `{ created: 0 }` at status 200.
- **Migrations are generated by `drizzle-kit generate`** (not hand-written). Live apply (`set -a; . ./.env.local; set +a; npx drizzle-kit migrate`) is **user-gated** — pause for go-ahead.
- **Throttle cadence: every 6 messages** in a project chat. **Pending cap: 10** per project.

- **Verification gate:** `npm run lint` (0 errors; ~26–30 warnings is baseline), `npm run typecheck`, `npm run build`, `npm test`. All green before merge.
- **Branch:** `feat/auto-memory` off `master`. Solo dev → no PRs; merge direct to `master` (`--no-ff`) after gate + user approval, then tag `v4.10.0`.
